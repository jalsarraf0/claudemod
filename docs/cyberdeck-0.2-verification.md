## Review fixes in 0.2.1

An independent whole-change review reproduced three defects against the published checkpoint. Regression tests were run failing before these fixes and passing afterward:

- Capture the session generation before permission checks or command state reads, and check again before external dispatch and after result publication. Clear, resume, or end cannot dispatch an obsolete task or return its old answer.
- Keep Grok's concurrency reservation until the underlying HTTP request settles, even after the 120-second user-facing deadline. Session changes also retain occupied slots. There are at most two outstanding client requests, with no automatic retry.
- Reserve two cells for emoji presentation and keycap sequences. Strip complete OSC title/link metadata, leaving visible text. Clipped labels remain bounded on narrow terminals.

The test host fixtures now include the actual engine's process-output flags, usage timestamp, event results, pane properties, and session-resume input. CI uses the required `[self-hosted, unified-all]` runners.
